Four things to remember

  • One platform, many outputs. Every artifact is a versioned, shareable page on the same hosting and sandbox. Types add editors and data contracts on top.
  • Capabilities are the only door out. Data, state, identity, files and AI reach the page through viewer-granted capabilities, never direct network calls.
  • Viewer identity is the boundary for live data. Live queries run as whoever is looking. Stored content is visible to everyone who can open the page.
  • Dashboards trades flexibility for auditability. A tighter page sandbox and a Sources pane make every number traceable, at the cost of source control and reuse.

    Anatomy of a dashboard Reported

    • One HTML page, with charts drawn by d3. Every number must come from a dataset.
    • Each dataset is one table, up to 8 MB, either a live connection or a file extract.
    • The Sources pane lists each number's query, rows and freshness. A file icon marks an extract and braces mark a calculation done in the page.
    • Storage per dashboard showed 100 MB for the database and 1 GB for files. Files in the dashboard's own store are capped at 256 KB, page included.
